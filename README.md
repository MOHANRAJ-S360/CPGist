# CPGist Website

Responsive, single-page CPGist marketing website built from the provided source package's design direction and content themes.

## Deploy

This is a static website. It can be deployed directly to Vercel by connecting this repository; no build command or environment variables are required.

## Notes

- The dashboard figures are synthetic, illustrative examples and are labeled accordingly.
- The contact form opens the visitor's email application; it does not submit data to a backend.
- Authentication and live analytics require a separately configured application/backend.
